================================================================================
WHAT IT DOES
================================================================================

BlastRadius visualizes the full impact of compromised npm packages using:
- Graph-based dependency analysis (powered by HydraDB)
- Interactive visualizations (dependency graphs, timelines)
- Maintainer risk analysis and typosquat detection
- Real-time search across 50+ known compromised packages

Think of it as a "security radar" that shows:
1. Which packages are compromised
2. What services are affected
3. How deep the attack goes (dependency chains)
4. Who maintains the packages (risk scoring)

HOW TO RUN
================================================================================

DEVELOPMENT
  1. npm install
  2. Add HYDRA_DB_API_KEY to .env
  3. npm run dev:all
  4. Open http://localhost:5173

PRODUCTION
  1. npm run build
  2. Deploy dist/ folder
  3. Set HYDRA_DB_API_KEY environment variable

VERCEL
  1. vercel --prod
  2. Add HYDRA_DB_API_KEY in dashboard

================================================================================
API ENDPOINTS
================================================================================

Backend API (http://localhost:3001/api):

  GET  /health                    → Health check
  POST /search                    → Search package blast radius
  GET  /suggestions               → List compromised packages
  GET  /relations/:id             → Get entity relationships
  POST /simulate-compromise       → Run simulation
  POST /maintainer-analysis       → Analyze maintainer risk
