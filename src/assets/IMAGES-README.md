# Graph Visualization Images

## Required Images

Save the following images to this directory:

### 1. graph-3d.png
**Description:** 3D isometric graph with orange center node and red compromised node  
**Usage:** Hero section, empty state, or graph view background  
**Dimensions:** ~1024x600px recommended

### 2. graph-network.png
**Description:** Blue network graph with interconnected nodes  
**Usage:** Graph view icon, documentation, or alternative visualization  
**Dimensions:** ~800x600px recommended

### 3. graph-blueprint.png
**Description:** Technical blueprint-style graph on grid paper  
**Usage:** Maintainer intelligence view, technical documentation  
**Dimensions:** ~1024x600px recommended
